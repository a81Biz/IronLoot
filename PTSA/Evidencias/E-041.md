# E-041 — La superficie que el usuario recibe, medida por primera vez

## Qué se midió, y cómo

La auditoría recorrió **el producto desde la pantalla**, no desde el servicio: las 42 plantillas de los
dos SSR, el layout y las 28 vistas de ADMIN, los 12 ficheros de JavaScript de navegador, los dos CSS, y
**los contratos reales del API contra lo que cada plantilla lee**.

Tres medidas se tomaron **en vivo**, con el sistema levantado, y son las que sostienen los hallazgos más
graves:

```
$ curl -s "http://localhost:3000/api/v1/auctions?status=ACTIVE&limit=6"
{"data":[],"total":0,"page":1,"limit":6}          ← no existe la clave `items`

$ curl -o /dev/null -w "%{http_code}" http://localhost:5175/auth/register
404                                                ← el CTA de registro del detalle público

$ curl -o /dev/null -w "%{http_code}" http://localhost:5174/terms
301                                                ← la canónica redirige a /static/terms
```

Y dos se calcularon con la fórmula de WCAG 2.1:

```
#C89B3C sobre #FFFFFF  →  2,56:1   (AA exige 3:1 incluso en texto grande)
#6B7280 sobre #F6F6F6  →  4,47:1   (AA exige 4,5:1)
```

## El resultado

**62 hallazgos** `H-UI-001` … `H-UI-062` — 11 P0, 30 P1, 16 P2, 5 P3 — más **36 ausencias** y **28
contradicciones** entre documentación, interfaz, funcionalidad y legales. Durante la corrección
aparecieron **dos más**, `H-UI-063` y `H-UI-064`.

## Por qué esta evidencia importa más que su recuento

**El sistema estaba certificado `Health 100 / Clase A / cero hallazgos activos` el día anterior**
(S-013, sobre `98e445b`), y entre esa emisión y esta medición **no hubo un solo commit de código**.

Las dos cosas son ciertas a la vez, y esa coexistencia es el hallazgo `H-038`.

## Lo que esta evidencia NO es

**No es un delta sync.** Los cinco checkpoints no se re-ejecutaron: `audit:domain` y `audit:reliability`
necesitan una base **con historia** y la base está vacía (`total: 0`, medido arriba) porque `run-all.sh`
la truncó. Emitir una puntuación sobre eso sería inventar un veredicto, que es exactamente lo que
`PT-180` enseñó a no hacer.

Es una **auditoría dirigida** que registra hallazgos. La puntuación la moverá el próximo `resume PTSA`,
cuando haya datos que medir.
