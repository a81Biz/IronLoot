# E-042 — Un webhook fabricado obtuvo `SIGNATURE_OK` y alcanzó la captura

## Cómo se capturó

`QA-PP-15` falló con `HTTP 400` en **las tres corridas** de `run-all.sh` del 2026-07-31
(`20260731-200936`, `20260731-202113`, `20260731-203031`). No es un fallo intermitente.

Reproducido a mano, con el API en pie y las cinco cabeceras que PayPal exige:

```
$ curl -o /dev/null -w "%{http_code}" -X POST \
    http://localhost:3000/api/v1/payments/webhook/PAYPAL \
    -H "paypal-auth-algo: SHA256withRSA" \
    -H "paypal-cert-url: https://api.sandbox.paypal.com/cert.pem" \
    -H "paypal-transmission-id: falso-1" \
    -H "paypal-transmission-time: 2026-08-01T00:00:00Z" \
    -H "paypal-transmission-sig: ZmFsc2E=" \
    -d '{"id":"WH-FALSO","event_type":"CHECKOUT.ORDER.APPROVED","resource":{"id":"X"}}'
400
```

## La secuencia, en el log del API

```
info   Received PayPal webhook CHECKOUT.ORDER.APPROVED (WH-FALSO)
info   Capturing PayPal order X
warn   PayPal respondio 404   httpStatus 400   code VALIDATION_ERROR
       at PaypalProvider.captureOrder (paypal.provider.ts:697)
       at PaypalProvider.handleWebhook (paypal.provider.ts:474)
```

**Entre «recibido» y «capturando» no hay ningún rechazo.**

## La traza, desde la otra punta

```sql
SELECT step, outcome FROM payment_cycle_events ORDER BY id DESC LIMIT 3;

 NOTIFICATION_RECEIVED | OK
 SIGNATURE_OK          | OK
 PROVIDER_CREATE       | OK
```

## El contraste que aísla la causa

La misma petición **sin** las cuatro cabeceras adicionales devuelve **401 correcto**:

```
Rejecting PayPal webhook — missing header(s): auth_algo, cert_url, transmission_id, transmission_time
httpStatus 401 · code UNAUTHORIZED
```

Es decir: **la comprobación de presencia de cabeceras funciona; la de validez de la firma devolvió
`SUCCESS`** sobre `ZmFsc2E=`.

## Lo que esta evidencia no dice

**No dice por qué** `/v1/notifications/verify-webhook-signature` respondió `SUCCESS`. Las tres hipótesis
—permisividad del sandbox, cuerpo mal formado en la consulta, o `PAYPAL_WEBHOOK_ID` que no corresponde—
**no se han medido**, y separarlas es el trabajo de `PT-234`.

Tampoco dice que ocurra en producción. Se midió en sandbox, y eso es todo lo que se afirma.
