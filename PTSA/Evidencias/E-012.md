# E-012 — Los documentos declarados auditables estan fuera del control de versiones

## Contenido capturado

```
$ for f in CLAUDE.md 02-PRD.md 03-TRD.md 09-Security-Architecture.md 06-Backend-Architecture.md
  do git check-ignore -q "$f" && echo IGNORADO || echo versionado; done

CLAUDE.md                                                IGNORADO por git
docs/enterprise-documentation/02-PRD.md                  IGNORADO por git
docs/enterprise-documentation/03-TRD.md                  IGNORADO por git
docs/enterprise-documentation/09-Security-Architecture.md IGNORADO por git
docs/enterprise-documentation/06-Backend-Architecture.md  IGNORADO por git

$ git ls-files docs/enterprise-documentation/ CLAUDE.md | wc -l
0
```

Y `audit-scope.yaml` los declara explicitamente:

```yaml
coverage_targets:
  docs:
    - CLAUDE.md
    - docs/enterprise-documentation/02-PRD.md
    - docs/enterprise-documentation/03-TRD.md
    - docs/enterprise-documentation/09-Security-Architecture.md
    - docs/enterprise-documentation/06-Backend-Architecture.md
```

## Observacion

**Los cinco documentos que el alcance declara auditables son invisibles para git.** `.gitignore:121`
ignora `docs/` entero, y `CLAUDE.md` aparte.

Esto no es una molestia: **rompe el mecanismo del propio delta sync**. F11 exige como evidencia el
«diff de commits desde la ultima auditoria», y `score_freshness` se define sobre
`commits_since_audit` **sobre patrones auditables**. Para estos cinco, ese numero **no se puede
calcular**: no es 0, es *indeterminable*.

## Efecto concreto sobre esta sesion

1. La frescura de D4 no se puede derivar de commits. Se ha sustituido por **comprobacion directa
   del contenido**, que es mas fuerte pero no escala ni se automatiza.
2. La guarda `coherencia-deuda-tecnica.spec.ts` (PT-103) **se salta a si misma en cualquier clon
   limpio y en CI**, por esta misma razon. Esta declarado en su propio codigo.
3. No hay forma de saber **quien** cambio una afirmacion de la documentacion critica, ni cuando.
   Durante esta sesion se corrigieron cuatro afirmaciones falsas en esos documentos (PT-109); ese
   cambio no deja rastro auditable.
